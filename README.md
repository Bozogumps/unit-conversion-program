# Unit Conversion Program

A Python project developed for PROG 1003 – Programming Logic 1.

## Overview

This program converts user-provided values between 14 units of measurement for length and volume. It uses an interactive menu to let users select a measurement type, enter a value, and view the equivalent measurements in the other units.

## Features

- Converts between 7 units of length and 7 units of volume
- Uses reusable functions for unit conversions
- Validates user input and handles invalid entries
- Formats results to four decimal places with thousands separators
- Allows users to perform multiple conversions in one session

## Technologies

- Python 3

## How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the program using:

   `python Conversions.py`

Replace `Conversions.py` with your actual Python filename if it's different.
